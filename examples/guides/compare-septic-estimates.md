# How to compare septic installation estimates

> Educational sample: Out West Septic is this library's chosen example business. This article demonstrates useful customer education; it is not a project estimate, system design, or permit determination. [Read the teaching notes](../../annotations/compare-septic-estimates.md).

Two septic estimates can have different totals because they describe different jobs. One may include clearing an access route, while another assumes the property is ready for equipment. One may include planning coordination; another may cover only installation using plans supplied by the owner.

Before choosing a contractor, make the scope comparable. Ask each bidder to explain what the price covers, what remains uncertain, and what you must arrange separately. The goal is a written picture of the whole project, not simply a shorter list of charges.

## Start with the same project information

Give each bidder the same property location, intended building use, [available site evaluation](planning-septic-before-building.md), and current plans. Identify the version and date of any drawings. Explain whether this is a new installation or work involving an existing system, and share known access restrictions.

Ask whether the number is preliminary or based on a site visit and defined plan. If the proposed system or layout differs between bids, ask why before treating the totals as alternatives for the same work.

TCEQ directs property owners to confirm the applicable process with their local authority. Use the [permit questions guide](septic-permit-questions.md) to organize that discussion; an estimate does not establish that a particular system is suitable or authorized. [TCEQ: Getting a permit for an OSSF](https://www.tceq.texas.gov/permitting/ossf/ossfpermits.html).

## Compare the scope line by line

Use a separate column for each estimate. Record the written answer or mark the item as unresolved until the bidder clarifies it.

| Part of the project | Question to put beside each estimate |
| --- | --- |
| Evaluation and planning | Who arranges these steps, and are their fees included? |
| Permits and inspections | Who submits documents, pays fees, coordinates visits, and handles requested revisions? |
| System components | Which components and quantities does the estimate include, and which plan defines them? |
| Equipment and access | Are delivery, mobilization, access preparation, and any return trips covered? |
| Excavation and site work | What is included for clearing, excavation, material handling, backfill, and cleanup? |
| Connections and electrical work | Where does this contractor's work begin and end? If electrical work is needed, who provides it? |
| Existing system | If applicable, what work involving the old system is included or assigned elsewhere? |
| Surface restoration | Does completion mean rough grading, or are topsoil, seed, landscaping, and driveway repairs included? |

An unanswered item is a question to resolve. It is not automatically evidence of poor workmanship or an unreasonable price. Ask for a revised written scope when an explanation changes what the estimate includes.

## Separate allowances from fixed amounts

Ask which amounts are fixed for the stated scope and which are allowances or estimates subject to later information. For every allowance, ask what assumption it uses and how the final charge will be calculated.

For a hypothetical example, one bid includes hauling surplus excavated material away; another assumes that material stays in an owner-approved location on the property. Neither description tells you which total is better until you decide what outcome you need. Have both bidders price or describe the same outcome before comparing them.

Ask how unexpected conditions would be documented, priced, and approved. Agree on a written change process before work begins, including whom the contractor contacts and whether work pauses while you review a proposed change.

## Discuss timing, payment, and completion together

Ask what must happen before the contractor can schedule the work and which dependencies could affect the proposed dates. Record the payment milestones, what each milestone covers, and the estimate's expiration date.

Clarify what the contractor considers complete. Ask which inspection or approval documents, system layout information, product instructions, warranty terms, and care information you will receive. Identify the contact for questions after installation and any ongoing services you must arrange separately. These are questions to agree on, not a promise that every bid includes the same package.

## Send a useful follow-up

A concise follow-up can be: "Please confirm the plan your estimate uses, list exclusions and allowances, identify work I must arrange, and explain how changes and final handover will be handled."
